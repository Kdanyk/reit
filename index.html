INSTALL REIT+

У Firefox натисни Ctrl + Shift + B, щоб показати панель закладок. Потім перетягни кнопку INSTALL REIT+ на панель закладок.

Можливості

REIT+ додає панель для підрахунку продуктивності, REIT/h, Problem Solve, Off Task та статистики зміни.

  • Автоматичний підрахунок сканувань
  • Підрахунок REIT/h
  • Problem Solve Tracker
  • Off Task Timer
  • Збереження статистики
