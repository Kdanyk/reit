C-RET V5
INSTALL C-RET

Тепер C-RET працює через розширення Tampermonkey.
Натисни велику кнопку вище для автоматичного встановлення (якщо файл c-ret.user.js є в папці), або скопіюй код вручну.

Що нового у V5?

  • Повна інтеграція з Tampermonkey (Shift+Z, Shift+X)
  • Віджет став мінімалістичним та "розумно" прозорим
  • Плавні бокові панелі для таблиці та налаштувань
  • Можливість паузи темпу на час перерви (30 хв)
  • Відображення темпу у відсотках (%)
